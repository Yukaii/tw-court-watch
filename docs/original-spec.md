# 旁聽 / 觀庭 Side Project — Spec

> 給下一個 agent 的執行規格。來源是司法院「庭期表查詢系統」的版面分析，目標是做一個現代化、手機友善的旁聽入口 + 觀庭筆記，而不是複製官方系統。
> 語言：繁體中文（台灣）。日期一律用民國年 + 西元年對照顯示，不要只寫民國年。

## 0. 參考來源（已驗證 2026-11-19）

- 官方查詢頁：https://csdi3.judicial.gov.tw/judbp/wkw/WHD1A03.htm
  - 標題：庭期表查詢系統，司法院資訊處製作
  - 國民法官版：https://csdi3.judicial.gov.tw/judbp/wkw/WHD1A03B.htm
  - 智慧客服（庭期表、開庭進度）：https://cs.judicial.gov.tw
- 影片脈絡：法律百科《法科！輕鬆點》S7EP08，法院開庭可以旁聽，行前先查庭期表；進法院要過金屬探測門、隨身物品 X 光；法庭門開著就能進旁聽席；法官進場、宣判要起立；庭內禁錄音錄影拍照、手機靜音、禁大聲喧嘩、吃東西、鼓掌；可以帶筆記本做筆記。
- 同類參考（不要抄，只看概念）：民間「觀庭筆記」——多人共筆還原法庭問答順序與語境、讓不同立場的人透過筆記溝通；護童行動聯盟的旁聽資訊頁——開庭時間、地點、旁聽席數、領證規則。

## 1. 產品定位

**一句話：** 讓一般人 3 分鐘就能找到「今天／這週可以去旁聽的庭」，去了之後能留下有用的觀庭筆記。

**目標使用者：**
1. 好奇的一般民眾（第一次旁聽）
2. 法律系學生、法庭觀察員、社工、記者
3. 想追特定案件進度的人（但不是當事人）

**不是什麼：**
- 不是官方庭期表複製品，不宣稱即時、完整、具法律效力
- 不是直播、錄音、逐字稿平台（庭內禁錄音錄影，這是紅線）
- 不是法官個人評分／爆料平台，不做人身攻擊、不點名未成年人與家事案件當事人
- 不提供法律諮詢、不預測判決

## 2. 官方站格式分析（照抄重點，改掉痛點）

### 2.1 整體結構（現況）
- 外層頁面幾乎沒有標題、導覽，實質內容在 1 個 iframe 內

- 送出查詢前沒有結果表，結果欄位、分页、排序方式**尚未驗證**，實作前要再查一次
- 建議瀏覽器：Microsoft Edge 或 Chrome，解析度 1024×768 以上（明顯是舊版設計）
- Footer：司法院資訊處製作，聯絡信箱 judadmin@judicial.gov.tw

1. 下載所有法院股別分配表 txt 檔

### 2.4 說明 5 項（官方原意，轉寫成新站的免責聲明）
1. 庭期僅供參考，以實際開庭通知單為準；查無庭期請逕向該管法院查詢
2. 本系統僅提供尚未開庭之庭期查詢，不提供已開庭期之查詢
3. 家事事件不公開審理，除經審判長或法官許可，不得旁聽
4. Android 庭期表查詢程式需 Android 2.2（含）以上版本（舊資訊，新站直接刪掉，改寫響應式設計說明）
5. 對系統有疑議建言歡迎來信

### 2.5 官方站的痛點（新專案要解決的）
- iframe + 1024×768，手機難用
- 81 項下拉無搜尋、無分組捷徑
- 日期要手打民國年 7 碼（1060115），容易打錯
- 法庭、股別要「開窗」另開彈窗
- 沒有地圖、交通、旁聽席數、是否需領旁聽證的資訊
- 沒有「今天可以看什麼」「新手推薦」「收藏／行事曆」這種旁聽導向的入口
- 沒有觀庭後的記錄、分享機制

## 3. 新專案功能範圍

### MVP（第一版，只做這 5 件事）
1. **找庭**：法院＋日期區間＋案件類別篩選，結果以卡片／列表呈現，手機優先
2. **庭期詳情頁**：日期、時間、法院、法庭、股別、案號、案由、是否公開、可否旁聽、交通／地址、旁聽席資訊（若官方有公告才寫，沒有就寫「依現場公告」）
3. **新手指南**：一頁式旁聽守則（安檢、起立、禁錄音錄影拍照、靜音、禁飲食鼓掌、可做筆記），直接用影片那 6 點
4. **我的清單**：收藏庭期、加入行事曆（.ics 下載）、出發前提醒文案
5. **觀庭筆記（簡版）**：旁聽後可寫一則公開筆記，欄位見 §5；不需登入也能看，寫筆記才需簡單驗證

### V2（MVP 上線後再做）
- 開庭進度（當日哪件正在開）
- 國民法官案件專區（沿用官方 WHD1A03B 的篩選邏輯）
- 依案件類型／關鍵字訂閱、每週「值得旁聽」推薦
- 法院地圖、交通、無障礙資訊
- 觀庭筆記的標籤、搜尋、按法院／法官（只寫股別，不寫姓名）彙整

### 明確不做
- 爬蟲即時同步官方資料庫、不做高頻輪詢
- 付費、帳號收費、廣告
- 法官個人評分排行榜（見 §6 風險）
- 上傳錄音／錄影／照片（庭內禁止）

## 4. 資料來源與更新策略（重要，先確認再實作）

1. **第一優先：連到官方查詢頁，不要自建資料庫假裝即時。** MVP 的「找庭」結果頁，每筆都要附「到司法院查詢頁確認」連結，點開就是官方 WHD1A03.htm 帶入相同篩選條件（若官方不支援帶參數，就只連到查詢頁首頁，並在 UI 上說明）。
2. **沒有公開 API 是已知事實。** 實作 agent 要先確認：官方有沒有公開 API／開放資料；若沒有，MVP 用「人工精選＋連結回官方」的方式，不要寫爬蟲。
3. 若未來要做資料快取：只快取公開庭期表（法院、日期、法庭、案號、案由），更新頻率每天一次，標明快取時間與「以官方通知為準」；不要快取當事人姓名、地址等個資。
4. 家事、少年、性侵、家暴等不公開案件一律不列、不寫筆記，UI 上要擋。

## 5. 資料模型（建議，agent 可微調欄位名）

### Hearing（庭期）

court_level: 'supreme' | 'high' | 'district' | 'simple'

case_no: string          // 如 115年度訴字第123號，年度同時存 ROC + 西元

date: string             // YYYY-MM-DD
time: string             // HH:mm
is_open_to_public: boolean
needs_ticket: boolean | null  // 是否需領旁聽證，null = 未知
seats: number | null
address: string
source_url: string       // 官方查詢頁連結
cached_at: string | null
```

### ObservationNote（觀庭筆記）
```
id: string
hearing_id: string
court, date, courtroom: string // 冗餘，方便列表
attended_at: string
summary: string          // 200–1000 字，寫程序與觀察，不寫逐字證詞
tags: string[]           // 如 準備程序、言詞辯論、宣判、國民法官

```

```

## 6. 內容與法律紅線

- 每頁頁尾固定放：庭期僅供參考，以法院實際開庭通知為準；家事事件不公開；庭內禁止錄音、錄影、拍照。
- 筆記審核規則：禁止當事人全名、地址、電話、未成年人資訊；禁止逐字還原證詞、禁止臆測判決；禁止對法官／當事人的人身攻擊。違規先下架、再通知作者。
- 「評分」只評程序體驗（清楚度、指引友善度），不做「法官好壞排行榜」，不彙整成個人分數。
- 不要用「法庭評級」這種會誤導的字眼當產品名，產品名建議用「旁聽」、「觀庭」方向，待使用者定。

## 8. UI 規範（給 agent 的設計約束）

- Mobile-first，單欄；桌面最大寬度 960px，結果列表卡片式，不要用官方那種 2 欄表格表單
- 顏色：中性底＋一個主色，不要用司法院藍當主色，避免看起來像官方站
- 字體：系統字體即可，標題 20–24px，內文 16px，行高 1.7
- 日期元件：原生 date input＋快捷 chips（今天／明天／本週末／未來 7 天）
- 法院選擇：可搜尋下拉，分組顯示，常用法院置頂
- 無障礙：所有按鈕要有文字標籤，篩選變更要有結果數量即時回饋（「找到 12 場」）
- 空狀態：查無庭期時寫「這個區間查無尚未開庭的庭期，試試放寬日期或換法院」，並附官方查詢連結

## 9. 技術建議（可換，但要說明理由）
